# Reprodukció

`npm test` – teljes offline regresszió.

`npm run test:stress` – 245 tesztlevél és 11 kapacitásválasz-teszt.

`node tests/email-stress-report.mjs /tmp/sarberki-stress.json` – minden levél értelmezése és három csatorna válasza JSON-ban.

A részletes hibanapló a hibanaplo.md; a mért összesítések a summary.json fájlban vannak.
